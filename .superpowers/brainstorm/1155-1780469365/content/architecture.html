📱 前台（客户看到的部分）

页面结构与导航流程
首页 🏠 品牌门户
✨ 首屏大图 (Hero) → 🔥 明星产品推荐 → 📖 品牌故事 → 📍 页脚联系
产品页 🎂 产品展示
分类筛选 (蛋糕/面包/甜点) → 精美卡片列表 → 点击查看详情 → 一键下单
详情页 🍰 产品详情
大图轮播 → 产品描述+规格 → 价格选项 → 加入购物车
下单页 🛒 下单结算
购物车清单 → 填写备注要求 → 选择支付方式 → 提交订单 ✓
