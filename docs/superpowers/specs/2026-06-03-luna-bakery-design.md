# 鹿呐烘焙 — 品牌网站设计规格书

> 日期：2026-06-03 | 状态：已确认

---

## 一、项目概述

为"鹿呐烘焙"打造一个高端烘焙品牌网站，兼具产品展示、在线下单、后台管理三大核心功能。客户通过微信生态访问，商家通过后台快速管理产品和订单。

### 品牌定位
- **名称**：鹿呐烘焙
- **调性**：高端、大气、灵动、温润治愈
- **Slogan**：用鹿的灵韵，焙出生活的甜
- **客群**：年轻女性、下午茶、日常甜品+定制蛋糕送礼

---

## 二、视觉设计系统

### 2.1 风格方向：暖调奶油（B方案）
- **主背景**：#faf7f2 奶油白
- **主文字**：#4a3728 暖木棕
- **点缀色**：#c4a882 淡金
- **辅助暖色**：#f5f0e8 / #ede0d0
- **页脚底色**：#4a3728 深棕反白

### 2.2 字体
- **标题**：Georgia / Noto Serif SC（衬线体，高级感）
- **正文**：PingFang SC / 系统无衬线（可读性）

### 2.3 设计原则
- 大留白、大行距，呼吸感
- 圆角柔润（8-12px），不锋利
- 光晕渐变点缀，温暖不刺眼
- 动效克制：卡片微浮、图片渐显、滚动渐入
- 所有页面元素风格统一，前台后台同一色彩体系

## 三、网站架构

### 3.1 前台页面（客户侧）

| 页面 | 路由 | 核心内容 |
|------|------|----------|
| 首页 | `/` | Hero品牌区 → 明星产品（模糊渐隐） → "查看全部"展开 → 品牌故事 → 页脚 |
| 产品详情 | `/product/[id]` | 大图轮播 → 名称+价格 → 描述 → 规格选择 → 数量 → 备注提示 → 加购/立即购买 |
| 购物车 | `/cart` | 产品清单+数量修改 → 合计+运费 → 去结算 |
| 下单结算 | `/checkout` | 手机号+称呼 → 备注框 → 订单摘要 → 提交 |

### 3.2 后台页面（商家侧）

| 页面 | 路由 | 核心功能 |
|------|------|----------|
| 登录 | `/admin/login` | 密码登录 |
| 仪表盘 | `/admin` | 新订单数+在售产品+今日收入 → 快捷入口 → 最近订单 |
| 产品管理 | `/admin/products` | 列表（分类筛选） → 新增 → 编辑 → 预览 → 上下架 → 删除（二次确认） |
| 订单管理 | `/admin/orders` | 订单列表 → 详情（备注高亮） → 状态标记（待确认/已确认/已完成） |

## 四、关键交互设计

### 4.1 明星产品区 → 查看全部
1. 首页展示4款明星产品（2×2网格）
2. 底部模糊渐隐区——blur(6px)幽灵卡 + 奶油白渐变遮罩，暗示后面还有产品
3. CTA按钮"查看全部12款产品 ↓"浮于遮罩终点
4. 点击后原地展开，2列网格显示全部产品 + 顶部胶囊分类筛选
5. 左上"←返回首页" + 底部"↑收起"双向返回

### 4.2 下单流程（严格三步）
```
🛒 购物车 → ✍️ 填写信息 → ✅ 下单成功
```
- 不强制注册，只需手机号+称呼
- 备注框76px高，引导文案"定制祝福语、口味偏好、配送时间都可以写在这里"
- 订单摘要始终可见

### 4.3 后台产品管理（增删改查）
- **新增**：空白表单→上传图→填信息→发布（3步）
- **编辑**：同一表单预填数据→修改→保存
- **删除**：二次确认弹窗，"删除后无法恢复"
- **上下架**：开关切换，下架保留数据，前台不显示

## 五、技术方案

### 5.1 整体架构：H5网页 + 微信内嵌
- 响应式设计，手机优先（375px基准）
- 通过微信公众号菜单打开
- 同时支持独立浏览器访问

### 5.2 技术栈

| 层级 | 技术 | 理由 |
|------|------|------|
| 前端框架 | Next.js 14 (App Router) | React生态，SSG/SSR兼备，SEO友好 |
| 样式 | Tailwind CSS + 自定义主题 | 快速开发，设计令牌统一管理 |
| 后端 | Next.js API Routes | 前后端一体，无需额外服务器 |
| 数据库 | PostgreSQL (Supabase) | 免费额度足够，自带存储和API |
| 图片存储 | Supabase Storage | 和数据库同一平台，管理简单 |
| 管理后台认证 | 简单密码登录 + JWT | 无需复杂用户系统 |
| 部署 | Vercel | 免费托管，自动部署，全球CDN |
| 域名 | 用户自行购买绑定 | — |

### 5.3 数据库结构

**products 表**
- id, name, category, price, description, image_url, tags, is_active, created_at

**orders 表**
- id, customer_name, customer_phone, notes, items (JSON), total_amount, status, created_at

### 5.4 通知方案
- 新订单 → 微信公众号模板消息通知商家
- 备选：短信通知 / 邮件通知
- 订单状态变更可通知客户
